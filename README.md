# ProCV - Premium CV Generator

Run:
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000

Developer photos -> put 3 images in  static/img/team/  named:
    m1.jpg  (Habibullah Jamali)
    m2.jpg  (Mutahar Khoso)
    m3.jpg  (Sabeen Channa)
jpg / jpeg / png / webp all work. If a photo is missing, initials are shown.

Fonts: Poppins (SIL Open Font License) is bundled in /fonts and embedded in the PDF.
